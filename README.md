# Impulse Growth Success — Data Analytics Capstone Project

## Business Overview
This project analyzes ride-share user patterns to design a data-driven marketing strategy aimed at converting casual riders into annual members.

## Tech Stack & Methodology
* **Database & Querying:** BigQuery SQL (CTEs, Aggregations, Data Cleansing)
* **Visualization:** Tableau (Interactive Executive Dashboard)

## Key Insights
1. **Usage Peak Disparity:** Casual riders peak during weekends (leisure use), while annual members peak on weekdays during regular commute hours (7 AM–9 AM, 5 PM–7 PM).
2. **Ride Duration:** Casual riders average 2x longer ride durations per session compared to members.

## Strategic Recommendations
* **Weekend Conversion Campaign:** Target high-volume weekend riders with targeted digital incentives for annual membership transitions.
* **Tiered Pricing Adjustments:** Implement seasonal or off-peak promotions tailored to long-duration casual users.
